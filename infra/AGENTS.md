# Infraestructura

Esta área podrá alojar infraestructura futura una vez que sus requisitos estén definidos.

- Prefiere infraestructura reproducible y configuración declarativa cuando corresponda.
- No guardes secretos en el repositorio y aplica el principio de mínimo privilegio.
- Separa los entornos cuando se definan.
- Documenta los cambios de infraestructura y sus implicaciones.
- No elijas todavía proveedor cloud ni arquitectura de despliegue.
