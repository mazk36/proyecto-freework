# Convenciones de desarrollo

- Sigue las instrucciones de `AGENTS.md` raíz y las del área modificada.
- Prefiere cambios pequeños, legibles y enfocados en el requisito aprobado.
- Conserva las convenciones que ya use cada herramienta o formato del proyecto.
- No asumas un lenguaje, framework o herramienta antes de que se defina el stack.
- Valida entradas externas, controla errores explícitamente y no registres datos sensibles.
- Documenta decisiones y contratos relevantes; evita comentarios y documentación redundantes.
- Antes de entregar un cambio, revisa el diff y ejecuta las comprobaciones pertinentes disponibles.
