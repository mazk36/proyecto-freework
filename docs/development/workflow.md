# Flujo de trabajo

```text
Requirement
↓
Clarification
↓
Design
↓
Implementation
↓
Tests
↓
Review
↓
Documentation
↓
Commit
↓
Push
```

Aclara el requisito antes de diseñar e implementar. Revisa el cambio, actualiza la documentación necesaria y valida con las herramientas disponibles antes de crear el commit y hacer push. Registra los cambios estructurales y las decisiones arquitectónicas importantes en la documentación y, cuando corresponda, en un ADR.
