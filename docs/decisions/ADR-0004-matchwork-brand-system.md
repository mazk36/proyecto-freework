# ADR-0004: Identidad visual de MatchWork

## Estado

Parcialmente reemplazado por ADR-0005 para el logo y la landing pública.

## Contexto

La marca aprobada presenta a MatchWork como un marketplace centrado en problemas y especifica un sistema de logotipo, color, tipografía, geometría e interacción. La interfaz anterior tenía una identidad negra y morada que no representaba ese sistema.

## Decisión

- Usar el wordmark `MatchWork`, con `Match` en azul noche `#0B2A5B` y `Work` en morado `#8A4DFF`, junto con el monograma compacto MW.
- Aplicar una base clara con Mist `#F5F7FB`, superficies Soft White `#F8FAFC`, texto azul noche y acentos controlados en morado y lavanda `#D8C4FF`.
- Usar Sora para encabezados y wordmark, Inter para la interfaz y JetBrains Mono para etiquetas técnicas.
- Aplicar nodos conectados, bloques modulares, esquinas redondeadas y líneas que se cruzan como recursos geométricos comunes.
- Reservar Match y sus badges para expresar encaje e interés mutuo en continuar la conversación.
- Mantener el significado de Match definido en ADR-0002: no equivale a contratación, pago ni contrato.

## Consecuencias

- La marca visual es compartida por la web pública, acceso, aplicación privada y metadatos.
- La landing conserva sus llamadas principales `Publica tu problema` y `Resuelve un problema`, y explica cómo se forma un Match.
- Esta decisión sustituye el tema oscuro negro y morado de ADR-0003; las rutas, autenticación temporal y separación pública/privada no cambian.

## Referencia visual

La guía aprobada es la lámina `MatchWork — Core Identity Master Board` proporcionada por el usuario. Este documento registra sus reglas principales para mantenerlas disponibles durante el desarrollo.
