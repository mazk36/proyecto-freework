# Packages / UI

Este paquete podrá alojar componentes visuales compartidos.

- Diseña componentes reutilizables y accesibles, sin reglas específicas del negocio.
- Mantén simples las APIs de componentes y evita componentes gigantes.
- Documenta las variantes que sean relevantes para su uso.
- No añadas un framework o sistema de diseño sin una decisión aprobada.
