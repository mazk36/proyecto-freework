# Pruebas

- Mantén las pruebas deterministas y evita servicios externos reales cuando no sean necesarios.
- Usa nombres descriptivos y prueba comportamiento observable, no detalles internos.
- Evita mocks excesivos.
- Prioriza casos críticos del negocio, casos límite y validación.
- No añadas pruebas triviales únicamente para elevar la cobertura.
