# Freework

Freework es un proyecto en etapa inicial para conectar empresas con freelancers mediante un enfoque centrado en problemas. Las empresas describen una necesidad y los freelancers pueden proponer distintas soluciones.

## Estado

El proyecto está en etapa inicial. El stack tecnológico y la arquitectura detallada todavía están siendo definidos.

## Estructura

- `apps/`: espacios previstos para las aplicaciones web y API.
- `packages/`: espacio previsto para componentes y código compartido.
- `docs/`: visión de producto, arquitectura, decisiones y proceso de desarrollo.
- `infra/`: espacio previsto para infraestructura futura.
- `scripts/`: espacio previsto para herramientas internas.
- `tests/`: espacio previsto para pruebas.

Consulta [la visión del producto](docs/product/vision.md) y las instrucciones en `AGENTS.md` antes de proponer cambios.
